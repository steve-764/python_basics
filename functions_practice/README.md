# Functions Practice Questions

## Q1. Basic Function

Write a function called `greet` that prints:

`'Habari! Welcome to Python class.'`

Then call the function.

---

## Q2. Function with Repeated Calls

Write a function called `show_line` that prints a line of 30 dashes.

Call it three times in a row.

---

## Q3. M-Pesa Menu Function

Write a function called `mpesa_menu` that prints a simple M-Pesa menu:

- Send Money
- Withdraw
- Check Balance
- Exit

Call the function once.

---

## Q4. Function with a Parameter

Write a function called `greet_student` that takes a `name` parameter and prints:

`'Habari, [name]! Ready to code?'`

---

## Q5. Times Table Function

Write a function called `print_times_table` that takes a number parameter and prints its times table from 1 to 10.

---

## Q6. Function with Multiple Parameters

Write a function called `add_mpesa` that takes two parameters:

- `sender`
- `amount`

Print a transfer message.

**Example:**

`'Amina sent Ksh 500 via M-Pesa.'`

---

## Q7. Function that Returns a Value

Write a function called `add` that takes two numbers and returns their sum.

Store the result in a variable and print it.

---

## Q8. VAT Price Calculator

Write a function called `vat_price` that takes an original price and returns the price after adding **16% VAT** (Kenya's standard VAT rate).

---

## Q9. Pass/Fail Function

Write a function called `is_pass` that takes a score and returns:

- `True` if the score is 50 or above.
- `False` otherwise.

Test it with several scores.

---

## Q10. Average Function

Write a function called `average` that takes a list of numbers and returns the average.

Test it with exam scores.

---

## Q11. Optional Function Parameter

Write a function called `make_tea` that takes:

- `cups`
- An optional `sugar` parameter with a default value of `1`.

Print a message like:

`'Making 2 cups of tea with 1 spoon of sugar.'`

---

## Q12. Multiple Parameters with an Optional Parameter

Write a function called `send_message` that takes:

- `recipient`
- `message`
- An optional `channel` parameter with a default value of `'SMS'`.

Print:

`'Sending to [recipient] via [channel]: [message]'`

---

## Q13. Receipt Generator

Write a program that uses functions to calculate and print a shop receipt.

Use separate functions for:

1. Calculating the subtotal.
2. Applying a discount.
3. Adding VAT.
4. Printing the receipt.

---

## Q14. Student Grade Calculator

Write a program using functions that takes a student's:

- Name
- Three subject scores

The program should:

1. Calculate their average.
2. Assign a grade using the following scale:
   - **A:** `>= 70`
   - **B:** `>= 60`
   - **C:** `>= 50`
   - **D:** `>= 40`
   - **F:** below `40`
3. Print a student report.

Use a **separate function for each task**.
