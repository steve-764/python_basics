# Personal Budget Calculator

Use `print()`, variables, data types, `input()`, arithmetic operators, and f-strings.

## Instructions

- Ask for the user's name and monthly salary (as an int).
- Ask for 4 monthly expenses by name and amount — all as int: rent, food, transport, other.
- Calculate `total_expenses` = sum of all 4 expenses.
- Calculate `savings` = salary - total_expenses.
- Calculate `savings_percent` = (savings / salary) × 100.

Print a full budget report using f-strings, showing:

- Name and salary
- Each expense on its own line
- Total expenses
- Savings amount
- Savings as a percentage, rounded to 1 decimal place

## Test your program with these values
- Salary: 50000
- Rent: 18000
- Food: 8000
- Transport: 4000
- Other: 5000

Expected result: savings = Ksh 15,000 (30.0% of savings)
